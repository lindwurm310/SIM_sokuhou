OPPOが、ハイエンドスマホ「**Find X10**」シリーズ2機種を**12月17日（木）**に日本で発売します。正式な発表は**12月10日**で、価格はまだ公開されていません。

## 2機種の違い

| 項目 | Find X10 | Find X10 Pro Max |
|---|---|---|
| 画面 | 約6.6インチ 有機EL（最大144Hz） | 約6.8インチ 有機EL（最大144Hz） |
| チップ | Dimensity 9600M | Dimensity 9600 Pro |
| メモリ／ストレージ | 12GB＋256GB／512GB | 12GB＋512GB |
| カメラ | 約2億画素（広角）＋約2億画素（2.8倍望遠）＋約5000万画素（超広角） | **約2億画素×3**（超広角・広角・3倍望遠） |
| 電池 | 8000mAh（80W急速充電） | 8000mAh（80W急速充電） |
| おサイフケータイ | **対応** | 非対応 |
| 防水・防塵 | IPX8・X9、IP6X | IPX8・X9、IP6X |
| 重さ | 約216g | 約233g |
| アップデート | OS 3回以上、セキュリティ4年以上 | OS 5回、セキュリティ6年 |
| カラー | グレイシャーブルー、ミストグレー | ルナホワイト |

どちらもSIMは2枚使え（nanoSIM／eSIMの組み合わせ）、別売のテレコンバーターキットでさらに望遠撮影ができます。

## どこで買える？

いまのところキャリアでの取り扱いは発表されていません。AmazonのOPPO公式ストアや、楽天市場のOPPO公式店での販売が案内されています。価格やキャリアの取り扱いは、12月10日の発表後にあらためてお伝えします。

## どんな人におすすめ？

- スマホのカメラで遠くのものまでキレイに撮りたい人
- 電池持ちを重視する人（8000mAh）
- おサイフケータイも使いたい人はFind X10を
